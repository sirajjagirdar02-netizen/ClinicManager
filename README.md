# Clinic Manager - Android

1. Push this folder to a private GitHub repository.
2. Open the **Actions** tab, select **Build APK**, and wait for it to finish.
3. Download the **clinic-manager-debug-apk** artifact and install `app-debug.apk` on an Android phone
   (allow "Install unknown apps" for your file manager or browser).

The app is the clinic HTML page (`app/src/main/assets/clinic_app_v3.html`) shown in a WebView.
Data is stored on the phone. PDF creation needs internet for the jsPDF library.
